# 绩点计算器 (GPA Calculator)

一个微信小程序，用于管理大学课程成绩并计算绩点，支持通过本地代理服务器从教务系统自动抓取成绩。

> **版本**: v1.2.1
>
> 变更记录见 [CHANGELOG.md](CHANGELOG.md)。
>
> ⚠️ 本项目仅供学习交流。抓取教务系统数据请遵守学校相关规定，勿用于非法用途。

## ✨ 功能特性

- **自动导入成绩**：输入学号密码，通过代理服务器登录教务系统，自动抓取全部学期成绩并导入
- **手动粘贴导入**：从教务系统复制成绩表格，粘贴到小程序解析导入（备选方案）
- **多 GPA 算法**：燕理算法（默认）、标准4.0、北大算法、浙大算法、WES算法、加拿大4.3、公式法
- **课程管理**：添加/编辑/删除课程、按学期筛选、排除公选课与体育课（可手动覆盖）
- **历史快照**：每次修改自动留档，可在「历史」页恢复到任意状态（保留最近 50 步）
- **统计分析**：学分统计、成绩分布、各学期绩点趋势
- **数据本地化**：课程数据存储在本地缓存，不上传第三方

## 🚀 快速开始

### 1. 启动代理服务器

项目自带 `server/server.js`，使用 Node.js 原生模块，**无需安装任何依赖**。

```bash
cd server
node server.js
# 🎓 绩点计算器代理服务已启动
#    地址: http://localhost:3000
```

> 代理服务器用于解决小程序无法直接跨域访问教务系统（HTTP + Cookie 会话）的问题。

### 2. 配置微信开发者工具

1. 打开微信开发者工具 → 导入项目 → 选择本项目目录
2. 点击右上角「详情」→「本地设置」
3. 勾选 **「不校验合法域名、web-view（业务域名）、TLS版本以及HTTPS证书」**（教务系统为 HTTP，需关闭校验）
4. 手机调试时，确保电脑与手机在同一局域网；接口地址默认走正式域名 `https://xiaofengzhulin.xyz`，本地调试可调用 `api.setApiBase('http://电脑局域网IP:3000')` 临时切换，调试完用 `api.resetApiBase()` 恢复

### 3. 使用

1. 首页点击「教务系统导入成绩」（深色大按钮）
2. 输入学号与教务系统密码 → 点击「登录并导入成绩」
3. 服务器自动登录教务系统并抓取成绩 → 导入完成自动返回首页
4. 也可切换到「手动粘贴」模式，复制教务系统成绩表格粘贴解析

## 🌐 网页版（功能与小程序一致）

`deploy/site/` 是一套纯静态网页版，用于网站备案（公安备案要求网站可被访问）和桌面端使用。无框架、无构建、无外部 CDN，把 4 个文件丢到 Nginx 目录就能跑。

| 能力 | 小程序 | 网页版 |
|---|---|---|
| 课程增删改、按学期筛选 | ✅ | ✅ |
| 7 种 GPA 算法切换 | ✅ | ✅ |
| 公选课 / 体育课自动排除，手动加入或排除 | ✅ | ✅ |
| 成绩分布、学期趋势统计 | ✅ | ✅ |
| 撤销 / 重做 / 历史快照恢复 | ✅ | ✅ |
| 教务系统导入（学号密码） | ✅ | ✅ |
| 手动粘贴成绩表格导入 | ✅ 文本 | ✅ 文本 + 直接粘贴整张表格 |
| 数据存储 | 小程序本地缓存 | 浏览器 localStorage |

```bash
# 本地预览
node tests/serve-site.js
# → http://127.0.0.1:8080

# 自测（无需安装任何依赖）
node tests/gpa-core.test.js      # GPA 算法 / 排除规则 / 表格解析 / 撤销栈
node tests/web-render.test.js    # 页面渲染与按钮交互（内置极简 DOM 模拟器）
node tests/web-static-check.js   # 事件绑定、资源引用、外链依赖、备案信息
node tests/miniprogram-util.test.js    # 小程序核心逻辑（注入 wx 桩，跑真实 util.js）
node tests/miniprogram-static-check.js # 小程序 WXML 绑定 / wx:key / 版本号一致性
```

> 网页版与小程序共用同一套算法口径：`deploy/site/gpa-core.js` 由 `miniprogram/utils/util.js` 移植，改动时请两边同步（`tests/gpa-core.test.js` 锁定了关键分档数值）。

## 📐 GPA 算法

以默认「燕理算法」为例（参考燕京理工学院教务处公告）：

| 分数 | 绩点 | 分数 | 绩点 |
|------|------|------|------|
| ≥95 | 4.67 | 77–79 | 3.00 |
| 90–94 | 4.33 | 74–76 | 2.67 |
| 87–89 | 4.00 | 70–73 | 2.33 |
| 84–86 | 3.67 | 67–69 | 2.00 |
| 80–83 | 3.33 | 64–66 | 1.67 |

完整算法见 `miniprogram/utils/util.js` 中的 `GPA_METHODS`。

## ⚠️ 注意事项

- **域名校验**：关闭域名校验仅对开发版/体验版有效，正式发布需配置 HTTPS 合法域名
- **数据安全**：账号密码保存在手机本地缓存；本地开发时传输未加密，请勿在公网开放服务器
- **登录保护**：`/api/login` 单 IP 20 次/分钟；同一学号连续失败 5 次锁定 1 分钟，再失败 5 次锁定 5 分钟，10 分钟内无新失败或登录成功即回到初始状态
- **教务系统稳定性**：教务系统可能调整页面结构，导致抓取失败，届时需同步更新 `server/server.js` 的解析逻辑

## 🛠️ 常见问题

**Q: 提示「服务器未连接」？**
A: 确认 `node server.js` 已启动；手机调试时确认 `api.js` 中的地址是电脑局域网 IP 且与手机同网段。

**Q: 提示「用户名或密码错误」？**
A: 教务系统返回该错误即为账号密码不正确，或需要先完成评教/改密。

**Q: 导入后绩点与实际不符？**
A: 不同算法结果不同，可在首页顶部点击算法名称切换 GPA 算法。

## 🧾 版本管理

- **版本号**：语义化版本 `主.次.修订`，如 `1.2.1`。修订号只修 bug、次版本号加功能、主版本号做不兼容改动。
- **三处必须一致**：`miniprogram/pages/about/about.js` 的 `version`、本 README 顶部版本、`CHANGELOG.md` 最新标题（`tests/miniprogram-static-check.js` 会校验，不一致直接测试失败）。
- **发布流程**：
  1. 改代码 → 跑全部自测（`node tests/xxx.js`，全绿）
  2. 更新 `about.js` 版本号 + `CHANGELOG.md` + README 版本号
  3. `git commit -m "v1.2.1: ..."` → `git tag v1.2.1`
  4. 微信开发者工具「上传」时填写同一版本号（如 `1.2.1`），备注写本次改动
- **历史版本**：`git tag -l` 查看，`git show v1.2.0` 查看某版本改了什么。
